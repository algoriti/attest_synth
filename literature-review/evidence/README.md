# Evidence archive

Upstream README, license and source snapshots are retained for review and attribution. Their original terms remain applicable; this folder does not relicense third-party material. Source-available BSL packages are included for technical comparison, not represented as permissively licensed platform dependencies.

- `repository_manifest.json`: exact upstream commits, access timestamps and file hashes.
- `source_manifest.json`: source-file retrievals including the failed REaLTabFormer path.
- `pypi_metadata.json`: observed released versions and declared requirements.
- `installed/`: source and license evidence from the actual installed benchmark wheels, with a separate hash manifest.
- `sources.json` / `sources.csv`: annotated research/software register.
- `software_inventory.md`: readable current software/license/version summary.

The bibliography links papers rather than redistributing complete publisher texts. A source in the register is not necessarily a full-paper replication; read depth is explicit. Upstream repository README/license snapshots are software documentation distributed under their respective project terms.
